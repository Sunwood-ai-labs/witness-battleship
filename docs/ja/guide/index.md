## 範囲を区別する

V62は35,761オブジェクトの全体基準。V102は船殻1＋付属13部品＋1グループの2区画比較で、全艦組立ではありません。比較検証は2/14区画、基準への採用は0区画です。新たなライセンスは付与していません。
