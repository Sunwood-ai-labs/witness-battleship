04 / VERIFICATION

Beyond a convincing image.

Public tools let you verify distribution integrity and the restored native file.

  • Match distribution file sizes and SHA-256 hashes
  • Verify all 16 parts, the combined ZIP, and the native FCStd
  • Never overwrite an existing restored output
  • Run geometry checks in a separate FreeCAD environment
