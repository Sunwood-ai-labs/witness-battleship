## 通常のPythonで再検証

リポジトリのルートで実行します。標準ライブラリで行う検査にはFreeCADは不要です。

```sh
python scripts/verify_files.py
python scripts/check_links.py
python -m unittest discover -s tests -v
python scripts/update_manifest.py --check
```

- `verify_files.py`：配布ファイルのサイズとSHA-256を照合します。
- `check_links.py`：Markdownのローカルファイル・画像参照先の存在を調べます。外部URLとページ内アンカーは検査対象外です。
- `unittest`：欠損、破損、不正な入力、出力の上書き拒否などのスクリプト動作を確認します。
- `update_manifest.py --check`：マニフェストと現状が一致するかを確認します。通常の利用時にマニフェストを書き換える必要はありません。

ハッシュ不一致は、破損だけでなく意図した編集でも発生します。配布物の検証と、自分の編集結果の検証を分けてください。不一致を消すためだけにマニフェストを更新しないでください。

## V62復元時の検証

```sh
python scripts/restore_v62.py
```

転送上限に合わせ、圧縮ファイルを16分割して配布しています。復元スクリプトは各片、結合した圧縮ファイル、復元FCStdのSHA-256を照合します。既存出力は上書きしません。復元手順は [はじめて開く・編集する](GETTING_STARTED.md) に記載しています。

## FreeCADで形状を検証

通常のPythonで `import FreeCAD` ができない場合は、FreeCAD内のPythonコンソールを使います。次のパスを、自分の取得先にある `scripts/verify_geometry.py` の絶対パスへ置き換えて実行してください。

```python
import runpy
runpy.run_path("/path/to/witness-battleship/scripts/verify_geometry.py", run_name="__main__")
```

上のパスは説明用のプレースホルダーです。Windowsでは `C:/.../scripts/verify_geometry.py` のように自分の取得先を指定できます。

スクリプトはBRepを読み取って検証し、モデルを保存・変更しません。検査内容：

1. 元船殻とV100/V101の別案船殻が、有効な単一ソリッドであること。
2. 元船殻との差分から計算した2つの除去領域が重ならないこと。
3. 2つの除去領域を引いた結果と、公開V102船殻との差分体積が許容値内であること。
4. `geometry/v102/` の14部品すべてが有効な単一ソリッドであること。

非重複の共通体積と、結果を双方向に引いた差分体積の和には、それぞれ `< 0.01`（FreeCAD形状の体積単位）の数値判定を用います。数学的な完全同一や製造上の許容差を保証するものではありません。配布された除去領域BRepはレシピ資料であり、このスクリプトの除去領域は別案船殻から再計算しています。

成功時には `PASS: 14 valid single-solid parts and exact two-cut recipe` と表示されます。この文言の `exact` は上記の数値判定の範囲です。

## 検証対象外

- FreeCAD 1.0R以外の互換性、全OS・全ハードウェアでの動作。
- 全艦の動作、強度、水密、製造適合性、安全認証。
- 全視点・全表示状態の再描画一致。
- 後続の局所成果をすべて取り込んだ全艦モデルの完成。
- すべての過去版・生成資料・履歴の完全復元。

既存のV101/V102保存原本では、新規フォルダーへの復元、native・payload・局所画像の再描画一致を検証済みです。ただし、公開派生版に対して新規に行った検査は本書の範囲であり、それを全艦の再検証へ拡大して解釈しないでください。
