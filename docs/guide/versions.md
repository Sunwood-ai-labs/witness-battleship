# Versions and public scope

**English** | [日本語](../ja/guide/versions.md) · [Guide index](index.md)

- **V62:** whole-ship baseline snapshot, not a latest whole ship containing every subsequent local addition.
- **V100:** first bay's 650 mm recess comparison.
- **V101:** adjacent bay's 500 mm recess comparison.
- **V102:** cumulative comparison subtracting both removal regions from the base hull; one complete hull and 13 attached shapes.

Public FCStd files are derivatives made from copies of the originals, with private working-directory and file-management identifiers removed from XML metadata. Unchanged ZIP members, including geometry BReps, are checked byte-for-byte against their originals. The originals are not modified.

The set excludes full working history, internal logs, private cloud identifiers and links, credentials, third-party messages, and personal backups.

This initial public set is not a mirror of the complete results archive. Some generation materials for past versions have not been located; complete historical recovery is not claimed.
