# WITNESS static homepage

Japanese: `index.html`. English: `en.html`. Both are generated by
`build_pages.py` from one structural template and parallel copy dictionaries.

## Build and preview

```sh
uv run python site/build_pages.py
uv run python -m http.server 8765 --directory site
```

Python 3 can also run these commands directly; no Python package or JavaScript
build dependency is required. The deploy artifact is this directory's HTML,
CSS, JavaScript, `.nojekyll`, and `assets/` files—not the native CAD collection.
The homepage works at the `/witness-battleship/` project path using relative
asset and locale links. Canonical/social URLs use the intended Pages address.

The source PNGs remain in `images/`. The eight site WebP derivatives retain the
actual CAD views, resized to a maximum of 1800 × 1100 pixels, with Pillow WebP
quality 86 / method 6. They are display assets, not new CAD renders or geometry
validation evidence. The complete collection is approximately 203 KiB.

## Interaction and accessibility

- Comparison buttons select whole view, BAY0, or BAY1.
- A labeled native range input supports pointer and keyboard comparison.
- Gallery buttons open a native modal dialog, with a close button, Escape
  support, restored trigger focus, and an original-resolution PNG link.
- Locale navigation uses separate complete documents, not a runtime translation
  dependency. Visible focus styles, a skip link, image alt text, and reduced
  motion support are included.
- No external fonts, analytics, JavaScript dependencies, cookies, or network
  services are needed for the page itself.

## Maintenance checks

After changing `build_pages.py`, regenerate both pages, then run the repository
site/link validators and inspect both languages at phone and desktop widths.
Check range controls with arrow keys, each comparison image pair, every gallery
image and original link, modal Escape/focus return, and all download/documentation
links. Structural checks are not a substitute for actual browser inspection.

Keep V62 (whole baseline) and V102 (local comparison) separate. The 2/14 local
bay count and zero baseline adoptions must never be labeled whole-ship completion.
