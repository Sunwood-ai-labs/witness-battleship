## V62：全体の基準

V62は35,761オブジェクトを持つ全体基準スナップショットです。後続の局所案をすべて取り込んだ最新版全艦ではありません。公開派生FCStdは16片の圧縮配布から復元します。

D4/D9の画像には後続の局所版を反映した表示用合成が含まれます。画像に見える後続成果がすべて公開V62へ統合されている、と解釈しないでください。

## V102：1つの船殻と13の付属形状

`geometry/v102/` には次の14個のBRepがあります。FCStdではこれらの14部品に1グループが加わります。

| ファイル名 | 数 | 役割 |
| --- | ---: | --- |
| `V102_TwoCutAlternativeHull.brp` | 1 | 2つの除去領域を適用した船殻 |
| `V102_FromV100_RecessBack.brp` | 1 | V100由来の凹部背面 |
| `V102_FromV100_RecessedWarmPane0.brp`〜`5.brp` | 6 | V100由来の暖色パネル |
| `V102_FromV101_RecessBack.brp` | 1 | V101由来の凹部背面 |
| `V102_FromV101_RecessedWarmPane0.brp`〜`4.brp` | 5 | V101由来の暖色パネル |
| **合計** | **14** | 船殻1＋背面2＋パネル11 |

BRepの単一ソリッド妥当性と切削レシピは検証対象ですが、これだけで全艦の構造安全や部品間の設計適合性を保証することはできません。

## 切削レシピ

`geometry/recipe/` の内容：

| ファイル | 内容 |
| --- | --- |
| `V62_OriginalHull.brp` | 元船殻 |
| `V100_AlternativeHull.brp` | 1区画目の650 mm凹部の別案船殻 |
| `V101_AlternativeHull.brp` | 隣接区画の500 mm凹部の別案船殻 |
| `REMOVAL_V100.brp` | V100に対応する除去領域 |
| `REMOVAL_V101.brp` | V101に対応する除去領域 |

V100とV101にはそれぞれ全船殻が含まれます。両方を重ねたり足し合わせたりしてV102にするのではありません。

```text
除去領域A = 元船殻 - V100の別案船殻
除去領域B = 元船殻 - V101の別案船殻
V102の船殻 = 元船殻 - 除去領域A - 除去領域B
```

検証スクリプトは別案船殻から除去領域を計算し、両領域の非重複と、結果が配布V102船殻と体積差の許容値内で一致することを確認します。詳しくは [検証記録](VERIFICATION.md) を参照してください。

## 画像とCADの対応を読む

- `WHOLE_BEFORE.png` / `WHOLE_AFTER.png`：全景で局所意匠の変化を見る比較画像。V102単体の部品構成を示す証拠ではありません。
- `BAY0_BEFORE.png` / `BAY0_AFTER.png`：5枚の暖色パネルを持つ区画の接写。
- `BAY1_BEFORE.png` / `BAY1_AFTER.png`：6枚の暖色パネルを持つ区画の接写。
- `D4_FLOOR_MAP.png`：食堂、厨房、共用室、医療・生活支援等を示す表示用合成。画像注記はV62＋V65/66/67/68＋V79を示しています。
- `D9_FLOOR_MAP.png`：上部艦橋の表示用合成。画像注記はV75の確定形状を示しています。

D4/D9では天井や切断面より上の形状が非表示です。D9の室内範囲は番号1で示され、他の暗色部分には別の屋根構造等が含まれます。画像はレイアウトの理解に使い、統合済みCADの代わりにはしないでください。

## 比較・採用・完成を分ける

現在は14区画のうち2区画の比較を検証した段階で、基準版への採用は0区画です。残り12区画は未完です。「2/14」は区画比較の範囲であり、全艦の完成率・再現率ではありません。
