# はじめて開く・編集する

## 1. 目的に合わせて選ぶ

- **全体の配置や外観を見たい：V62。** 35,761オブジェクトの基準スナップショットです。初回は16個の分割圧縮ファイルから復元します。
- **2区画の凹部を調べたい：V102。** 同梱FCStdを直接開けます。船殻1部品＋付属13部品＋1グループであり、全艦組立ではありません。
- **インストールせずに見たい：READMEの8枚の画像。** 全体、接写、D4/D9の配置を見られます。画像から統合状態や寸法精度を保証することはできません。

公開FCStdの新規オープンはFreeCAD 1.0Rで確認済みです。他のバージョンは未検証です。

## 2. 取得とファイル検証

```sh
git clone https://github.com/Sunwood-ai-labs/witness-battleship.git
cd witness-battleship
uv run python scripts/verify_files.py
```

Python 3を使用します。例は `uv` を優先しています。既存のPython環境では `uv run python` を `python` または `python3` に読み替えられます。検証に失敗した場合は、開いて編集する前に取得漏れ・変更を調べてください。

## 3. V62を復元する

```sh
uv run python scripts/restore_v62.py
```

入力は `cad/v62_parts/PARTS.json` と16個の `.part001`〜`.part016`、出力は `cad/WITNESS_V62_PUBLIC.FCStd` です。断片を個別にFreeCADで開くことはできません。

復元では各片・圧縮ファイル全体・出力FCStdを照合します。展開後ファイルも置ける空き領域を確保してください。必要メモリや処理時間は環境に依存し、固定の値は検証していません。

出力がすでに存在すると停止します。これはデータ保護のためです。既存ファイルが編集済みか分からない状態で削除しないでください。必要なら自分で管理できる場所へ退避し、由来を確認したうえで再実行します。

## 4. FreeCADで確認する

1. FreeCADを起動し「ファイル → 開く」から対象FCStdを選びます。
2. 読み込み完了後、全体が表示されるよう表示範囲を調整します。
3. モデルツリーで対象の形状を選び、プロパティと表示状態を確認します。
4. V102は部品数が少ないので、凹部の船殻と背面・パネルを分けて確認する入口に向いています。

比較は別々の文書で行い、同じ空間に船殻を重複させないでください。V100/V101の別案船殻BRepも全船殻を含み、追加部品として積み重ねるものではありません。

## 5. 編集は作業コピーで行う

- 最初に「名前を付けて保存」で、配布FCStdとは別の作業ファイルを作ります。
- 元ファイルを残すと、不具合が配布時点からあるか、編集後に発生したかを切り分けられます。
- 形状の種類や保持されているプロパティに応じて編集してください。完全なスケッチ・フィーチャー履歴の存在は保証していません。
- 形状変更後は保存して閉じ、新規に開き直して表示・部品・形状を確認します。
- 編集した画像やモデルを比較するときは、版、変更内容、表示条件を記録します。「比較案」と「採用済み基準版」を区別してください。

BRepの確認はFreeCADで対象 `.brp` を開く方法もありますが、形状データの確認用です。FCStdのグループ構造・色・編集履歴を丸ごと再現する手段ではありません。
