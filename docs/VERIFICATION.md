# 公開セットの検証

2026-11-01 の公開準備時点。

- V62公開派生FCStd：XMLの非公開作業パス・ファイル管理ID等のみ置換。その他107,342 ZIPメンバーは原本とSHA-256一致。FreeCADで新規に開き直し35,761オブジェクトを確認。
- V102 FCStd：59 ZIPメンバーが原本と一致。新規に開き直し15オブジェクトを確認。
- V102 BRep：14部品すべて有効な単一ソリッド。2除去領域の非重複と累積切削レシピの差分体積を確認。
- PNG：公開用コピーからテキスト等のメタデータを除去。除去前後の全RGBAピクセル一致を確認。
- 公開ツリーとFCStd内メンバーについて、秘密鍵・主要トークン形式・非公開クラウドID・内部作業パスをパターン走査。これはあらゆる未知の秘密を数学的に不存在証明するものではない。

既存のV101/V102保存原本については、保存先から取得したZIPを新規フォルダーに復元し、native・payload・局所画像の再描画一致を検証済み。この公開派生版の新規検査は上記の範囲で、全艦の動作・構造安全・全視点の再描画を再検証したとはしない。

本書は公開前のローカル検証記録です。公開先への反映はリポジトリのコミット履歴を確認してください。V62は転送上限に合わせて圧縮原本を16分割し、同梱スクリプトで各片・圧縮原本・復元FCStdのSHA-256を照合します。
