# 版と公開範囲

[English](../../guide/versions.md) | **日本語** · [ガイド一覧](index.md)

- V62：全体基準スナップショット。後の局所追加をすべて含む最新版全艦、という意味ではない。
- V100：1区画目の650 mm凹部比較。
- V101：隣接区画の500 mm凹部比較。
- V102：上記2つの除去領域を元船殻から引いた累積比較。1つの全船殻と13付属形状。

公開用FCStdは原本の複製から、非公開の作業ディレクトリやファイル管理IDなどをXMLメタデータ上で除いた派生版。形状のBRepを含む非変更ZIPメンバーは原本とバイト一致検証する。原本は変更しない。

全作業履歴、内部ログ、クラウド保存の識別子・非公開リンク、認証情報、第三者とのメッセージは含めない。既存の個人用バックアップは公開しない。

この初期公開セットは全成果アーカイブのミラーではない。過去版の生成資料には所在未確認のものもあり、全履歴の完全復元を主張しない。
